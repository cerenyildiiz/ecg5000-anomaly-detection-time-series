This folder contains the ECG5000 dataset used in this project.

| File | Description |
|------|-------------|
| `ECG5000.zip` | Original downloaded dataset archive. |
| `ECG5000_TRAIN.txt` | Original training dataset provided with the ECG5000 dataset. |
| `ECG5000_TEST.txt` | Original test dataset provided with the ECG5000 dataset. |
| `ecg.csv` | Combined CSV version of the training and test datasets used for model development. |
